## [1.0.0-beta.0] - 2026-05-12

### Initial Public Beta

First public beta release of Zorix — a schema-driven IndexedDB wrapper with a type-safe query API for modern web applications.

### Features
* Schema-driven database structure
* Type-safe query system
* IndexedDB abstraction layer
* CRUD operations support
* Browser-focused lightweight architecture
* Rollup-based package builds
* TypeScript support
* ESM, CJS, and IIFE bundle support

### Notes
* This is a beta release and APIs may change in future versions.
* Feedback, issues, and contributions are welcome.
